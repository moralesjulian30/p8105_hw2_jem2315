## Problem 1

``` r
stations_data = read_csv("data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv") |> 
  janitor::clean_names() |> 
  select(line, station_name, station_latitude, station_longitude, route1:route11, entry, vending, entrance_type, ada) |> 
  mutate(
    entry = case_match(entry, 
                       "YES"~TRUE,
                       "NO"~FALSE)
  )
```

This NYC transit subway data set contains information on New York City
subway station names, the latitude and longitude of the station, the
routes that run through them, if entry is permitted, vending
availability, what the entrance types are, and if they follow ADA
compliance. For data cleaning, I standardized all variable names using
clean_names(), kept only the variables needed for analysis using
select(), and converted the entry variable from a character variable to
a logical variable. This data set has 1868 rows and 19 columns. The data
set is not fully tidy because routes information is spread throughout
multiple columns (route1 through route11) instead of in a single
variable for route.
