## Problem 1

``` r
stations_data = read_csv("data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv") |> 
  janitor::clean_names() |> 
  select(line, station_name, station_latitude, station_longitude, route1:route11, entry, vending, entrance_type, ada) |> 
  mutate(
    entry = case_match(entry, 
                       "YES"~TRUE,
                       "NO"~FALSE)
  )
```

This NYC transit subway data set contains information on New York City
subway station names, the latitude and longitude of the station, the
routes that run through them, if entry is permitted, vending
availability, what the entrance types are, and if they follow ADA
compliance. For data cleaning, I standardized all variable names using
clean_names(), kept only the variables needed for analysis using
select(), and converted the entry variable from a character variable to
a logical variable. This data set has 1868 rows and 19 columns. The data
set is not fully tidy because routes information is spread throughout
multiple columns (route1 through route11) instead of in a single
variable for route.

## Problem 2

``` r
mrtrash_df =
  read_excel("data/202610 Trash Wheel Collection Data.xlsx", na = c(".", "NA", ""), sheet = "Mr. Trash Wheel", skip = 1, range = cell_cols("A:N")) |>
  janitor::clean_names() |>
  filter(!is.na(dumpster)) |>
  mutate(
    year = as.integer(year),
    sports_balls = as.integer(round(sports_balls)),
    trash_wheel = "Mr. Trash Wheel"
  )

proftrash_df = 
  read_excel("data/202610 Trash Wheel Collection Data.xlsx", na = c(".", "NA", "", "dive"), sheet = "Professor Trash Wheel", skip = 1, range = cell_cols("A:M")) |> 
  janitor::clean_names() |> 
  filter(!is.na(dumpster)) |>
  mutate(
    year = as.integer(year),
    trash_wheel = "Professor Trash Wheel")

gwyntrash_df = 
  read_excel("data/202610 Trash Wheel Collection Data.xlsx", na = c(".", "NA", ""), sheet = "Gwynnda the Good Wheel of the W", skip = 1, range = cell_cols("A:L")) |> 
  janitor::clean_names() |> 
  filter(!is.na(dumpster)) |> 
  mutate(
    year = as.integer(year),
    trash_wheel = "Gwynnda the Good Wheel of the W")

trashwheel_df =
  bind_rows(
    mrtrash_df,
    proftrash_df,
    gwyntrash_df
  ) |> 
  relocate(trash_wheel)

prof_weight =
  trashwheel_df |>
  filter(trash_wheel == "Professor Trash Wheel") |>
  pull(weight_tons) |>
  sum()

gwynda_butts =
  trashwheel_df |>
  filter(
    trash_wheel == "Gwynnda the Good Wheel of the W",
    month == "June", 
    year == 2022
    ) |>
  pull(cigarette_butts) |>
  sum()
```

The `trashwheel_df` data set contains merged information from Mr. Trash
Wheel, Professor Trash Wheel, and Gwynnda. The data set contains
information on trash collected at each trash wheel such as
`plastic_bottles, polystyrene, cigarette_butts, glass_bottles, plastic_bags, wrappers, sports_balls`,
their total weight in tons (`weight_tons`), and volume in cubic yards.
The data set has a total of 1269 observations. The total weight of trash
collected by Professor Trash Wheel was 294.96 while the total number of
cigarette butts collected by Gwynnda in June of 2022 was 18120.
